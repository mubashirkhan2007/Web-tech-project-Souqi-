PROJECT DESCRIPTION

SOUQI is a fictional online retail platform created for the COS10026 Applied Web Project. The website is designed to introduce the company, advertise available job positions, and allow applicants to submit job applications.

The website was developed using HTML5 and CSS3 only, without JavaScript or Bootstrap.

WEBSITE PAGES

1. index.html - Home Page
   Introduces SOUQI, its services, and career opportunities. Includes company branding, navigation, a search box, a hiring table with merged cells, and links to other pages.

2. jobs.html - Position Descriptions
   Displays two available job positions with job references, salaries, responsibilities, and requirements. Includes an aside section and links to the application page.

3. apply.html - Job Application
   Contains an HTML5 application form for applicants to enter their personal details, job reference number, and skills. Uses built-in HTML5 validation.

4. about.html - About Page
   Introduces G05 team members, their contributions, quotes with English translations, group photo, and fun facts.

CSS FILES

styles.css - Common styling used across the website.
index.css - Home page styling.
jobs.css - Jobs page styling.
apply.css - Application page styling.
about.css - About page styling.

IMAGES

The images folder contains the website's logos, photographs, and other image assets.

ACCESSIBILITY

The website includes semantic HTML5 elements, image alternative text, form labels, keyboard focus styles, and responsive CSS.

The website also includes an acknowledgement of Aboriginal and Torres Strait Islander peoples.
