# Souqi

Souqi is a fictional online retail platform hiring for its technical and user experience teams. This is a static recruitment website built with HTML5 and CSS3 only (no JavaScript or Bootstrap) for the Swinburne Applied Web Project, Assessment 2 (Part 1), scenario G05: E-Commerce & Digital Retail Platform.

## Pages

| Page | Purpose |
|------|---------|
| `index.html` | Home page with company overview, search box and hiring snapshot |
| `jobs.html` | Open job positions with requirements |
| `apply.html` | Job application form with HTML5 validation |
| `about.html` | Our team, contributions and fun facts |

`styles.css` is the shared external stylesheet.

## Features

- Semantic, validated HTML5
- Responsive layout and accessibility best practices
- Common navigation and footer on every page
- Acknowledgement of Aboriginal and Torres Strait Islander peoples

## Run locally

1. Clone the repo: `git clone https://github.com/YOUR-USERNAME/souqi.git`
2. Open the folder in VS Code
3. Right-click `index.html` and choose **Open with Live Server**

## Workflow

- Run `git pull` before you start working
- Work on your own page and commit from your own account
- Add CSS only in your page's section of `styles.css`
